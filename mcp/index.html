A working demonstration of AI access

This service demonstrates how a business can make selected information available directly to customers’ AI assistants. Here, it connects you to my published writing, featured book, and public information.

The same approach can help businesses make product information, documentation, and support resources easier to find and use. With additional integrations and permissions, it can also support tasks such as checking availability or preparing a quote. Those operational capabilities are examples of possible extensions; this demonstration provides public information only.

Connect your assistant

Add a custom MCP connection in your assistant’s settings using this address:

https://mcp.jamesburchill.com
  1. Open your assistant’s apps, connectors, or MCP settings.
  2. Choose the option to add a custom remote MCP server and paste the address above.
  3. Name it James Burchill and enable the connection.

No account or API key is required. Your assistant must support remote MCP using Streamable HTTP. Setup options and availability vary by application and plan. The address above is for an MCP client; opening it as a normal webpage will not start a chat.

Public information only

The service cannot access private files, customer records, email, or calendars, and it cannot send messages or book appointments. Public content refreshes on demand, with up to five minutes of caching.

Requests are processed on my server. The application does not retain your prompts or search terms; temporary connection information is used for rate limiting. Your AI provider’s own data policies still apply. Please do not send private information.
